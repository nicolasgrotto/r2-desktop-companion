# R2 Desktop Companion 1.3.0

Candidata local para Windows x64.

Na roda de ações, **Foco** inicia uma sessão com duração, tarefa opcional e
cartão de projeção. Uma sessão em andamento volta pausada ao reabrir o Companion.
O temporizador comum permanece disponível em **Ferramentas**.

Em **Música**, ative a integração para seguir a sessão atual do Windows ou
escolher um player da lista. Os controles dependem das capacidades que o player
publica. Os ensaios com provedores nativos de teste usaram Windows 10 22H2.
A compatibilidade com Windows 11 e players comerciais ainda precisa de validação.

Em **Configurações → Preferências**, escolha **Idioma / Language**, clique em
**Salvar idioma** e reinicie para usar Português (Brasil) ou English. As preferências também oferecem
redução de movimento, escala da interface e um atalho global opcional para
abrir **Buscar ações**.

Na **Droid Garage**, salve um tema de interface para cada personagem. Em
**Ferramentas → Minigames**, adicione links HTTPS pessoais, com ícone ou miniatura
importada de PNG/JPEG. O jogo abre no navegador padrão.

Extraia o ZIP por completo antes de abrir `R2Companion.exe`. O pacote portátil
inclui o runtime necessário. Ao atualizar a 1.2.2, a aplicação reutiliza
tarefas, notas, seleção e preferências. Se voltar à 1.2.2 e depois abrir a
candidata, os temas e minigames da 1.3 continuam no documento complementar.
