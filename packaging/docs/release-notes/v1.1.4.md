# R2 Desktop Companion 1.1.4

- Animated sleep symbols appear over the original droid, Vesper, and Orbita.
- **Project timer** displays the countdown on the droid's hologram, including pause and resume.
- The preference is saved. Closing Tools keeps the timer and its projection active until the countdown ends.
- The projection follows the hologram setting. Use **Project** to end or replace it.

## Installation and updates

Choose **Check for updates** in the Companion. To install manually, extract the entire ZIP and run `R2Companion.exe`. Keep `_internal` and `release.json` beside the executable. The portable build runs on Windows 10/11 x64 and includes its runtime.
