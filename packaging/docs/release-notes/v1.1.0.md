# R2 Desktop Companion 1.1.0

## What's new

- **Droid Garage.** Preview and equip the original droid, Vesper, or Orbita. Each has its own visual style, animations, sounds, and theme.
- **Distinct movement.** Vesper uses graphite and bronze artwork. Orbita rolls with independent head and body motion, gradual acceleration, and balance recovery after dragging.
- **Per-droid themes and audio.** Panels, menus, bubbles, holograms, and Update Center follow the equipped character. Audio Center previews samples and supports individual volume, mute, and category settings.
- **Animation Gallery.** Browse, play, repeat, stop, and inspect animation frames while the desktop mascot stays active.
- **Personality and appearance.** Choose Calm, Curious, or Talkative, pet the mascot's head, adjust the original droid's colors, or customize sensor lighting on the new droids.
- **Desktop tools.** Use diagnostics, holographic projections, and the Minigames catalog, which opens Duel of Fates in the default browser.
- **Quiet hours.** Autonomous behavior, audio, and notifications respect the configured quiet period and the desktop context.

## Updates and reliability

Update Center shows download and installation progress, checks SHA-256, and uses a backup for recovery. The interface follows theme changes through file events. This release also improves per-droid preferences, recovery after failed character changes, and cleanup of sound, timers, signals, and previews. Local validation recorded 299 passing tests and a Windows x64 build and smoke test.

## How to update

Choose **Check for updates** from the Companion menu. The updater checks the package, creates a backup, and restarts the app with the same tasks, notes, favorites, and preferences.

For a manual installation, extract all of `R2Companion-Windows-x64.zip`, then run `R2Companion.exe`. Keep `_internal` and `release.json` alongside it. The portable bundle targets Windows 10/11 x64 and includes its runtime. An installation already on 1.1.0 is considered up to date.

- Central de atualização em Qt com consulta e download assíncronos, progresso
  real, novidades da release e validação de SHA-256.

- A central recebe mudanças de tema por eventos do sistema de arquivos,
  incluindo gravações atômicas, sem consulta periódica de 750 ms.

  e recuperação segura após falhas na troca de personagem.
- Melhorias na liberação de áudio, timers, sinais e recursos de pré-visualização.
- **299 testes aprovados** na validação local, com build e smoke test Windows x64.

## Como atualizar

Na versão instalada, use **Verificar atualizações** no menu do Companion.
O atualizador baixa o pacote, verifica sua integridade, cria um backup e reinicia
o aplicativo. Tarefas, notas, favoritos e preferências anteriores são preservados.

Para instalar manualmente, baixe `R2Companion-Windows-x64.zip`, extraia **toda a
pasta** e execute `R2Companion.exe`. Preserve `_internal` e `release.json` junto
ao executável. Requer Windows 10/11 x64; não requer Python instalado.

Uma instalação que já informa 1.1.0 será considerada atualizada. Para exercitar
o fluxo de upgrade, a instalação de origem deve ter versão anterior à 1.1.0.
