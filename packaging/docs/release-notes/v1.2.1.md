# R2 Desktop Companion 1.2.1

O Temporizador agora tem o botão **Encerrar**, disponível durante uma contagem
em andamento ou pausada. Ele cancela o timer atual e libera os campos de duração,
os atalhos e **Iniciar contagem** para você definir outro intervalo imediatamente.

Encerrar não dispara o aviso de conclusão. A projeção do timer é removida; se
você escolheu projetar o relógio manualmente, essa projeção é preservada.

**Pausar/Continuar** mantém o tempo restante e **Reiniciar** volta à duração
original. Fechar a janela de Ferramentas continua deixando o timer em execução;
use **Encerrar** quando quiser cancelar a contagem.

A atualização preserva a seleção do droide, as preferências, os favoritos,
as tarefas e as notas. Inclui os refinamentos de animação da versão 1.2.0.
