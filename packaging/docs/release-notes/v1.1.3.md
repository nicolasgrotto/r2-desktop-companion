# R2 Desktop Companion 1.1.3

- Improved action-wheel reliability after double-clicks and rapid repeated clicks.
- A click on the mascot can close the wheel without reopening it on mouse release.
- Improved submenu selection during transitions and recovery from interrupted animations.
- Fixed display of Tools, Droid Garage, Audio Center, Preferences, and Favorites after updating.
- The confusion reaction from repeated clicks waits for navigation to finish.

## Installation and updates

Choose **Check for updates** in the Companion. To install manually, extract the entire ZIP and run `R2Companion.exe`. Keep `_internal` and `release.json` beside the executable. The portable build runs on Windows 10/11 x64 and includes its runtime.
