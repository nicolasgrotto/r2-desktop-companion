## 1.3.0

### Added

- Focus sessions with optional task links and projected countdowns. Active sessions resume paused after restart.
- Optional Windows media session controls, player selection, and music projection.
- Keyboard action search, a configurable global shortcut, and a first-steps panel.
- Free, Focus, and Presentation modes, with a description of each mode in Settings and the tray menu.
- English and Brazilian Portuguese, with an in-app restart button to apply the language.
- Reduced motion, 100%–150% interface scaling, and per-droid themes.
- Personal HTTPS minigames with preset icons or PNG/JPEG thumbnails.
- Undo for the last task or note deletion, JSON export for both collections, and UTF-8 export for individual notes.
- Backup timestamps and the option to restore tasks, notes, or both.

### Changed and fixed

- Adaptive projection cards follow the droid and stay visible beside the action wheel. The click greeting stays hidden during projection.
- Music projection clears when playback stops or the session disappears. The Music panel can end it directly.
- Click vocalizations can finish with the wheel open, without overlapping another sound.
- The mouse wheel scrolls the page over preference controls. Droids clear windows and reach fullscreen corners faster.
- Refined droid reactions and added a dedicated compass preset for Exploration minigames.
- Preserved productivity data and preferences when upgrading from 1.2.2.
